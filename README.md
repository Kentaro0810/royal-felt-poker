# ROYAL FELT 9-MAX HOLD’EM

あなた1人＋BOT8人のノーリミット・テキサスホールデムWebゲームです。架空チップのみで、現金・換金・課金機能はありません。

## 公開
1. ZIPを展開
2. GitHubに新規Publicリポジトリを作成
3. 全ファイルをリポジトリ直下へアップロード
4. Settings → Pages → Deploy from a branch → main / root → Save

依存関係・ビルド・APIキー・データベースは不要です。
